# Support

The AI Context Framework is an open-source project maintained on a **community, best-effort basis**. There is no dedicated support team, no SLA, and no customer support commitment.

## Getting Help

| Channel | Purpose |
|---------|---------|
| [GitHub Issues](https://github.com/DevonAleshireMSFT/ai-context-framework/issues) | Bug reports, documentation errors, and reproducible problems |
| [GitHub Discussions](https://github.com/DevonAleshireMSFT/ai-context-framework/discussions) | Questions, ideas, and community conversation (if enabled) |

Before opening an issue, please:
1. Check the [documentation site](https://devonaleshiremsft.github.io/ai-context-framework/) for existing guidance.
2. Search open and closed issues for similar reports.
3. Run `npm run validate` and `node --test` to rule out local configuration problems.

## What This Project Supports

Support applies to **the framework itself** — the CLI, validation scripts, templates, and documentation:

- Bugs in `bin/ai-context.mjs` or `scripts/`
- Errors in template files or documentation
- Broken links or incorrect instructions

## What This Project Does Not Support

- **Your adopter implementation** — how you fill in `.ai/context.md`, configure Copilot instructions, or structure your repository is your responsibility
- **AI model behavior** — GitHub Copilot and other AI tools are external products; questions about their behavior belong to their respective support channels
- **Enterprise deployment or configuration** — this project does not provide professional services, consulting, or enterprise support agreements

## Security Issues

For security vulnerabilities, please use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) instead of opening a public issue. See [SECURITY.md](SECURITY.md) for the full policy.

## Version Policy

Only the latest commit on `main` is actively maintained. See [SECURITY.md](SECURITY.md) for the supported versions table.
